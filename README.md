# Aqua Insights

"做一个污水处理智慧平台，6个一级菜单，要求：

污水处理相关科技风背景，污水处理相关配色为主色调，带污水处理风格背景图（颜色鲜明）

毛玻璃半透明卡片（透明度高一些，突出显示背景图），带流光渐变边框和hover浮起效果

顶部固定导航栏，左侧3个图标菜单+大标题居中+右侧3个图标菜单（菜单均为图标+文字形式，拉长一些），导航栏也要有玻璃质感

每个页面布局要有非常明显差异，不要千篇一律，内容要特别丰富多样：统计数据卡片 + 多种echarts图表（折线、柱状、雷达、饼图混排）+ 数据表格 + 状态指示器

数据要有立体感和色彩冲击力，整体炫酷、现代、有科技感"
