# 污水处理智慧平台

## 建设内容
- 打造固定顶部导航：左侧 3 个图标菜单、居中平台标题、右侧 3 个图标菜单。
- 使用鲜明的污水处理厂背景，并叠加高透明毛玻璃、流光边框与悬浮抬升反馈。
- 实现 6 个可切换一级页面：综合态势、水质监测、工艺运行、能耗分析、设备运维、预警中心。
- 每个页面采用明显不同的布局与信息层级，提供数据卡、趋势图、柱图、雷达图、饼图、表格、状态灯和流程视图。
- 图表统一采用立体高饱和青绿、蓝、金色体系；所有趋势图图例置顶并预留空间。

## 页面差异
- 综合态势：核心指标 + 厂区总览 + 水量趋势 + 达标率环图 + 实时水质表。
- 水质监测：水质核心指标 + 多指标趋势 + 污染物雷达 + 采样点数据表。
- 工艺运行：横向处理流程 + 各工段负荷柱图 + 池体参数矩阵 + 运行时间线。
- 能耗分析：能耗总览 + 峰谷曲线 + 能耗构成饼图 + 单耗排行与节能建议。
- 设备运维：设备健康总览 + 健康度雷达 + 维护排程表 + 在线状态矩阵。
- 预警中心：预警等级统计 + 24 小时预警柱图 + 风险分布饼图 + 事件处置列表。

## 技术细节
- React 单页交互，菜单切换即时更新内容。
- 使用现有图表库实现丰富图形，并保持图例、悬浮提示和自适应尺寸完整。
- 设计颜色、阴影、边框和玻璃效果集中定义，桌面和移动端均不重叠。
- 补齐页面标题、描述及社交分享元信息。
